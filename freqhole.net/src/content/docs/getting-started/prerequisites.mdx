freqhole can use [ffmpeg](https://ffmpeg.org/) and [yt-dlp](https://github.com/yt-dlp/yt-dlp).
which tools you need depends on where freqhole is running. browser and mobile
clients do not run these command-line tools themselves; features that use them
run on the native freqhole node.

---

## ffmpeg

`ffmpeg` and `ffprobe` are used for media probing, waveform images, and some
media-processing features. basic browsing and playback do not require a separate
install on every client.

**macOS and Windows**: the official Charnel desktop app bundles `ffmpeg` and
`ffprobe`; no separate install is normally needed.

**Linux**: the Debian and RPM packages declare `ffmpeg` as a dependency, and
the Flatpak build includes it. for an AppImage, manual build, or another package
that does not install dependencies, install the distribution's package yourself:

```bash
sudo apt install ffmpeg   # debian/ubuntu
sudo dnf install ffmpeg   # fedora
```

**rathole or development builds**: they may use tools installed on the system
instead of the Charnel app's bundled binaries. make sure `ffmpeg` and `ffprobe`
are on `PATH` when using features that need them.

---

## yt-dlp

needed only when a native freqhole node is configured to fetch media from URLs.
yt-dlp is not bundled with the desktop app. browser, Android, and iOS clients
cannot run it locally; URL fetching must be handled by a native node with
yt-dlp available.

**see** [github.com/yt-dlp/yt-dlp](https://github.com/yt-dlp/yt-dlp) for best installation instructions.

**macOS**:

```bash
brew install yt-dlp
```

**Linux**:

```bash
# pip (into a venv or with --break-system-packages on newer distros)
pip install yt-dlp

# or download the binary directly
curl -L https://github.com/yt-dlp/yt-dlp/releases/latest/download/yt-dlp -o ~/.local/bin/yt-dlp
chmod +x ~/.local/bin/yt-dlp
```

**Windows**:

```powershell
winget install --id yt-dlp.yt-dlp
```

freqhole will find yt-dlp automatically if it's in your PATH or a common install
location. for non-standard paths, set it explicitly in `freqhole-config.toml`:

```toml
[server.fetch_music]
fetch_command = "/full/path/to/yt-dlp ..."
precheck_command = "yt-dlp --print-json --no-download"
```

`precheck_command` enables the add-media review step before the download starts.
use a metadata-only yt-dlp command so freqhole can show what will be fetched
first.
