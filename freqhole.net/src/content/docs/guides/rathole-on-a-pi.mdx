## install

Raspberry Pi OS Bookworm/Trixie. arm64 supports **charnel** (desktop GUI) or
**rathole** (terminal); armhf supports rathole. charnel requires an existing desktop,
not Lite.

run as your regular account, **without sudo**:

```sh
curl -fsSL https://raw.githubusercontent.com/freqhole/tomb/main/scripts/raspberry-pi/setup.sh -o freqhole-setup.sh && bash freqhole-setup.sh
```

the download replaces `freqhole-setup.sh` in the current directory. review it before
running if preferred. don't pipe it into Bash: setup needs interactive input.

## choose your setup

- **charnel:** desktop-login autostart, optional player-first view and fullscreen/maximized window.
- **rathole tty1:** dedicated local player, no x-windows; replaces the tty1 login while running.
- **rathole SSH/tmux:** detached terminal session without taking over the local console.
- optional OLED + rotary encoder, manual Wi-Fi portal, and Plymouth splash image.

setup runs `apt-get update`, offers a system upgrade, then installs dependencies.
choose one app per run; rerun to add the other without removing its installation
or startup setting. desktop autologin/taskbar settings remain manual.

at the end: **Enter** starts the selected app, **r** reboots, any other key exits.
reboot for hardware/group/console changes.

## first launch

complete rathole's TUI or charnel's GUI wizard to choose the data directory and
create the database/root user. the installer does not choose that storage location.
with OLED controls, restart the app after the wizard to enable its control socket.

commands are installed in `~/.local/bin`. open a new Bash terminal, or update this one:

```sh
export PATH="$HOME/.local/bin:$PATH"
```

SSH/tmux:

```sh
freqhole-pi attach
```

detach with **Ctrl+B, then D**; playback continues. attach shows shortcut help and
offers to start a stopped session. from a Pi desktop terminal, launch charnel with:

```sh
charnel-session
```

pair a phone/controller using the [player pairing flow](/guides/cenotaph/).
the OLED's **new admin pairing** creates a single-use admin invite and shows it in
the app's pairing view; **rotate pairing pin** creates a member invite.

## manage

```sh
freqhole-pi                  # complete command help
freqhole-pi check
freqhole-pi update
freqhole-pi check charnel
freqhole-pi update charnel
freqhole-pi start            # rathole; also stop/restart
freqhole-pi disable          # stop and disable selected startup entries
freqhole-pi enable           # restore startup without launching
freqhole-pi poweroff
```

enable/disable: Enter selects all, numbers such as `1 3` select a subset, `q` cancels.
includes rathole, OLED and charnel desktop login; Wi-Fi stays manual-only.

the OLED checks releases at startup and daily. **check update** becomes
**install update** when a newer version is known; selecting it refreshes release
info and asks before installing. **reverse wheel** saves direction immediately.

optional Wi-Fi provisioning:

```sh
freqhole-wifi info
freqhole-wifi start          # may disconnect Wi-Fi/SSH; maximum ten minutes
freqhole-wifi status
freqhole-wifi stop
```
